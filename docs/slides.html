Quantitative Methodology

Unified Mathematical Target Formulation

All modules across backend and frontend strictly compute annualized percentage volatility:

1. Daily Log Returns

r_t = ln(P_t / P_{t-1})

2. 5-Day Forward Annualized Realized Volatility (Target)

σ_{5d} = sqrt( 252/5 * ∑_{i=1}^5 r_{t+i}^2 ) × 100%

3. GARCH(1,1) Conditional Variance

σ_t^2 = ω + α · ε_{t-1}^2 + β · σ_{t-1}^2   (SPY: α=0.1729, β=0.7930)
